# Criterios para habilitar una carta de control

Una métrica podrá entrar al módulo de control estadístico cuando cumpla:

1. Definición operacional estable.
2. Unidad de medida explícita.
3. Fuente o instrumento versionado.
4. Frecuencia de observación consistente.
5. Marca temporal confiable.
6. Población, cohorte o proceso claramente delimitado.
7. Cambios metodológicos registrados.
8. Datos faltantes identificados y cuantificados.
9. Reglas de exclusión documentadas.
10. Periodo base suficientemente estable.
11. Al menos 20 puntos para una evaluación inicial.
12. Preferiblemente 25 o más puntos para I-MR.
13. Al menos 20 subgrupos para Xbar-R o Xbar-S.
14. Al menos 20 periodos para P, NP, C o U.
15. Preferiblemente 25 a 30 puntos base para EWMA o CUSUM.
16. Revisión estadística, científica y pedagógica.
17. Prohibición de interpretar automáticamente correlación como causalidad.
18. Prohibición de usar señales aisladas para sancionar estudiantes o docentes.
19. Registro de quién revisó la señal y qué decisión tomó.
20. Recalibración de límites cuando cambien instrumento, población o proceso.
