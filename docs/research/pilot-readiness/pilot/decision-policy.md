# ILP Pilot-Readiness Decision Policy

## Principle

No production capability is modified solely because it appears in an
external educational framework.

A change is admitted only when it provides traceable value to at least
one of the following:

1. Research validity.
2. Pilot operation.
3. Data integrity or provenance.
4. Participant safety, privacy or authorization.
5. Testability or quality assurance.
6. Traceability of pedagogical decisions.

## Decisions

KEEP
Existing capability works and requires no change.

HARDEN
Existing capability works but requires stronger tests, evidence,
traceability, security or observability.

EXTEND
Existing capability is useful and should receive an additive capability
without breaking its current contract.

CREATE
A Pilot-1 or doctoral requirement has no adequate implementation.

DEFER
Useful capability that is not necessary for Pilot-1.

REJECT
Capability does not contribute enough value to justify its complexity.

## Change rule

Prefer:

reuse > harden > extend > refactor > replace

## Pilot rule

A capability is Pilot-1 blocking only when its absence compromises:

- consent or authorization;
- participant identification/pseudonymization;
- validity of an instrument;
- integrity of an observation;
- provenance;
- longitudinal linkage;
- required outcome collection;
- ethical/privacy requirements;
- reproducible dataset generation.
