# ILP-OAS external determination and preregistration package

This package is ready for institutional review but has not been submitted. It contains no approval, exemption, risk decision, personal data, expert rating or operational authorization.

The package supports two distinct future actions: (1) obtain written ethics, institutional and data-protection determinations; and (2) preregister the expert content-review methods before viewing real ratings. Neither action is performed automatically by R10.12A-A8.
