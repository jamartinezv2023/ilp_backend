# Plan de publicaciones y ciencia abierta

## Compendio provisional

1. Revisión de alcance y modelo conceptual.
2. Cocreación, validez de contenido y entrevistas cognitivas.
3. Estructura interna, confiabilidad, IRT e invariancia.
4. Recomendaciones explicables: utilidad, desempeño y equidad.
5. Implementación, accesibilidad, experiencia y validación externa.

Cada artículo responderá una pregunta diferenciada y evitará fragmentación
artificial de resultados.

## Estrategia de costo cero

- R y Python para análisis.
- Zotero para referencias.
- GitHub para código y trazabilidad.
- OSF o repositorio institucional para protocolos.
- Zenodo para versiones con DOI cuando proceda.
- Revistas sin APC o de acceso abierto diamante.

## Productos abiertos previstos

Protocolos, mapas de constructos, manuales, código de puntuación, código
estadístico, diccionarios, esquemas y datos sintéticos. La apertura estará
condicionada por ética, privacidad y propiedad intelectual.
