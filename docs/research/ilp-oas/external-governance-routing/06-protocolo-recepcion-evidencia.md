# Protocolo de recepcion de evidencia externa

A9 solo podra habilitarse con evidencia autentica recibida de autoridades identificadas. Un correo informal, llamada, captura aislada o evaluacion anual favorable no se clasifica automaticamente como autorizacion.

1. Registrar autoridad, fecha, asunto, alcance y condiciones.
2. Conservar el original sin modificar.
3. Calcular SHA-256 y registrar nombre, tamano y formato.
4. Verificar dominio, firma, radicado o mecanismo institucional.
5. Separar original y copias de trabajo.
6. Registrar expiracion y obligaciones.
7. No inferir autorizaciones que el documento no exprese.
8. Mantener datos personales fuera de Git y transcripciones.
9. Confirmar inconsistencias por canal oficial.
10. Habilitar A9 solo mediante intake que valide cada puerta.
