# Secure transfer and custody SOP

## Before collection

1. Name the institutional data controller and approved storage system.
2. Create reviewer codes using a non-meaningful random sequence.
3. Store identity linkage separately with restricted access.
4. Test encrypted transfer, access logging, backup restoration and deletion using synthetic data.
5. Freeze instrument versions, analysis decisions and file hashes.

## Distribution

Provide each eligible reviewer only the approved notice, instructions and instruments assigned to that reviewer. Use an approved authenticated channel. Never send item banks through public links or commit completed forms to Git.

## Receipt

Record receipt time, expected reviewer code, file hash and malware scan where applicable. Validate schema without changing responses. Quarantine unexpected files. Preserve the original immutable submission and create a pseudonymized analysis copy.

## Access and retention

Apply least privilege, encrypted storage, versioned backups and a dated access register. Execute retention, archival and secure deletion only under the approved institutional schedule.

## Prohibited actions

No credential sharing, personal USB transfer, public repository storage, chat transcription of personal data, silent correction of ratings, identity disclosure in analysis files or combination with student datasets.
