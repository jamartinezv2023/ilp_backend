# ILP-OAS expert content-review package

This package supports structured expert review of 84 candidate items from three original and distinct ILP instruments: ILP-EPL, ILP-MEA and ILP-IVP.

Package status: prepared, empty and not administered. It does not document completed expert review, psychometric validation, ethics approval, instrument licensing or readiness for field collection.

The package separates reviewer eligibility, construct references, item-level ratings, global instrument ratings, qualitative recommendations, rights/authorship review and reproducible analysis. The three instruments must never be pooled into a single score or treated as equivalents of Kolb, Felder-Silverman, Kuder or other third-party instruments.
